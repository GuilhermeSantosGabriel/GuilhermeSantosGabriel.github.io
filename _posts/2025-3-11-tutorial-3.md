**This series of posts serve to show my experiences following the "1st Phase: Linux kernel cycle" of the Free Software Development Course made by FLOSS at USP.**

### What i did

 This tutorial is focused on the linux kernel modules. The modules are basically "plug and play" parts of the kernel that can be inserted or removed during runtime!

We first started by making an example module called simple_mod. This module doesnt do anything specifically, but it informs us when it is loaded and unloaded. With this module i explored how to add this module to the kernel (configuring the "symbols" and making sure the module is compiled). I end the tutorial by loading and unloading the module and seeing it on the log using dmesg.
