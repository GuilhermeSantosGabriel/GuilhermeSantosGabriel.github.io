### What i did

This tutorial is a study of the iio_simple_dummy module. This module is a tool so that new developers can better understand how modules work and particularly how industrial input/output modules do. IIO modules are specialized for sensors like accelerometers, thermometers, etc. The tutorial explains the main struct that tries to group up most of the IIO devices we might need with different fields like what is being measured (type), how many channels the sensor has (indexed and channel) and more. 

### Problems

Quite hard to understand, so it took a lot more time than other tutorials for me to somewhat grasp it, but no straight up problems.
